# CAMmotion test board (rev 1)

A 2-layer, 80 × 60 mm calibration coupon for isolation milling, drilling and UV exposure.
It is also a DRC fixture: `features.json` lists every feature's size and position (mm, origin
at the board's lower-left corner), so tests and measurements can refer to them exactly.

Generated by `node tools/testboard/generate.mjs` — **do not edit these files by hand**.
Unlike the synthetic Gerbers they are committed, because they are what gets cut on the
machines; `test/unit/samples/test-board.test.js` fails if they drift from the generator.

## Features

| Feature | Layer | Values |
|---------|-------|--------|
| Trace width ladder | F.Cu | 0.10, 0.15, 0.20, 0.25, 0.30, 0.40, 0.50, 0.60, 0.80, 1.00 mm; 26 mm long, 1.6 mm pad at each end |
| Gap ladder | F.Cu | pairs of 0.8 mm traces, edge-to-edge gap 0.10, 0.15, 0.20, 0.25, 0.30, 0.40, 0.50, 0.60 mm |
| Drill ladder | PTH, both copper layers | 0.4 – 3.0 mm (12 sizes), 0.4 mm annular ring |
| Fine-pitch pad rows | F.Cu | 0.5 / 0.65 / 0.8 mm pitch (gaps 0.25 / 0.30 / 0.35 mm) |
| Aperture types | F.Cu | one pad each: circle, rectangle, obround, polygon (hexagon), rounded-rectangle macro; plus a region (G36/G37) pad and an arc (G03) trace |
| Fine text | F.Cu | "CAMMOTION" at 2.0 / 1.2 / 0.8 mm high, 0.20 / 0.15 / 0.10 mm strokes |
| Copper pour + mirrored text | B.Cu | region under the gap ladder; "BOTTOM" reads correctly from below |
| Alignment holes | NPTH | 2 × 3.0 mm at (3, 30) and (77, 30) — on the flip axis for double-sided milling |
| Outline | Edge.Cuts | 80 × 60 mm rectangle. Holding tabs are added by CAM (milestone 6), not drawn here |
| Mask / silkscreen | F/B.Mask, F.Silkscreen | mask openings = pads + 0.05 mm; silk title for viewer colour checks |

The `.gbrjob` file describes a 1.6 mm FR4 board with bare copper (`Finish: None`).

## Measuring (see `docs/qa/`)

After cutting, measure each ladder step and record it against `features.json` with date,
commit, machine, tool and photos. Systematic errors become machine-profile corrections and
a new automated test.
