# Machine QA

Required for any change to a post-processor or machine profile before its milestone closes
(AGENTS.md → Testing, PROJECT_PLAN.md → Machine QA). Copy `checklist-template.md` to
`results/YYYY-MM-DD-<machine>-<short-commit>.md`, fill it in, and commit it with the photos.

Measured errors become corrections in the machine profile **and** a new automated test.
